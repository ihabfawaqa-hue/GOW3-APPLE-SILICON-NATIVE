# Verified blockers

Updated: 2026-10-24. Evidence below separates capability failures from missing integration work.

| Severity | Blocker | Evidence | Next falsifiable action |
|---|---|---|---|
| Critical | The candidate Vulkan path cannot allocate the pinned sparse buffer cache on Apple M2. | KosmicKrisp and MoltenVK both report `sparseBinding=false` and `sparseResidencyBuffer=false`; pinned `BufferCache` unconditionally builds 1–4 GiB sparse BDA arenas and calls sparse binds. Earlier live run `run_20261024_054738_284387` reached candidate shader compilation and captured 211 black frames before a generic buffer-address failure. Current strict guard is verified by `run_20261024_055824_537005`. A new workload confirms that two independent BDA buffers can be dereferenced and written through a GPU page table on both drivers, but direct descriptor bindings, contiguous cross-range operations, alias coherence, and guest writeback are not yet covered. | Replace sparse arena backing with a bounded resident-range representation while preserving the BDA page-table contract. Adapt direct storage/vertex/index/indirect/copy/readback consumers and page-alias synchronization; test CPU/GPU writes and guest-visible readback. Do not allocate multi-gigabyte dense mirrors or bypass the feature check. |
