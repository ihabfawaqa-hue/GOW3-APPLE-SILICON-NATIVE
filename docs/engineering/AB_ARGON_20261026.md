# Alternating A/B of today's changes (2026-10-26)

`docs/handoff/bench/ab_argon.sh 2 120`: 10 runs of 250 s on a throwaway save copy, Metal HUD on,
alternating configurations, 120 s cooldown between runs. M2 MacBook Air, 16 GB, macOS 27.0.
**Not an idle machine**: load average before each run was 1.7 to 5.8 (the Claude app, Chrome and
ChatGPT were open, and README work ran alongside).

| Config | Library | `ps4_app` | Env |
|---|---|---|---|
| old | runtime 20261026-002350-614833b | TSO checks on | none |
| base | new (this HEAD) | TSO checks on | none |
| tsooff | new | TSO checks off (default now) | none |
| qos | new | TSO checks off | `PS4_THREAD_QOS=brbDriver=default`, `GOW3_COPY_QOS=initiated` |
| prep2 | new | TSO checks off | qos settings + `GOW3_PREP_WORKERS=2` |

## Light scene (about 727 draws per flip). The display caps it at 60 FPS.

| Run | Config | Load before | Mean FPS | p95 frame |
|---|---|---|---|---|
| tsooff_1 | tsooff | 3.6 | 59.6 | 16.7 ms |
| old_2 | old | 3.6 | **50.1** | **33.4 ms** |
| base_2 | base | 2.7 | 60.0 | 16.7 ms |
| tsooff_2 | tsooff | 2.1 | 59.8 | 16.7 ms |
| qos_2 | qos | 4.1 | 60.0 | 16.7 ms |
| prep2_2 | prep2 | 1.8 | 59.6 | 16.7 ms |

Every run on the new library sat at the 60 Hz cap, so this scene cannot tell the new configurations
apart. The one old-runtime run in it was lower and had 33 ms frames at p95. That is one sample, taken at
load 3.6, but all six new-library runs were smooth.

## Heavy scene (2,270 to 2,486 draws per flip). Round 1 only: round 2 never reached it.

| Run | Config | Load before | Mean FPS | p95 frame |
|---|---|---|---|---|
| base_1 | base | 3.4 | 39.4 | 33.4 ms |
| qos_1 | qos | 1.7 | 41.0 | 33.4 ms |
| prep2_1 | prep2 | 2.6 | 37.9 | 33.4 ms |

One sample each. The spread (37.9 to 41.0) is about the size of the run-to-run variation seen in
earlier identical runs, so none of these differences is established. The direction matches earlier
measurements: draw-prep workers did not help.

old_1 never reached gameplay (menu frames only) and is excluded.

## Reading

- Highest sustained gameplay frame rate: 60.0 mean (display-capped), in the light scene.
- Heavy scene: roughly 38 to 41 FPS on the new build in this test; earlier sessions recorded 38 to 45.
- No result here proves the TSO-off default or the QoS switches help. A conclusive test needs an idle
  machine, several rounds, and a way to land every run in the heavy scene.
