GOW3 ARM64 GPU INTEGRATION AUDIT
================================
Audited: 2026-10-23

LOCAL TREE STATE
----------------
This working tree does not contain the shadPS4 video core or shader recompiler.
There is no gpu/shadps4 directory, no shadPS4 submodule, and no Vulkan, SDL3,
MoltenVK, or KosmicKrisp entry in the active build.ninja link/build rules.

The local gpu/gow3gpu.h and gpu/gow3gpu_bridge.cpp are a small interface and
forwarding stub. The bridge forwards submissions and presentation to
ps4_gnm_metal_*; source search found no runtime call sites for gow3gpu_init,
gow3gpu_submit_command_buffers, or gow3gpu_present. The active GNM path in this
tree is sceGnmSubmitCommandBuffers -> ps4_gnm_metal_process_command_buffers,
and VideoOut calls ps4_gnm_metal_present. A runtime log from the Metal
initializer is required to confirm the backend for each run.

Therefore the earlier descriptions of a vendored shadPS4 implementation,
GoW3-specific Vulkan changes, a persistent staging pool, and page-fault-window
adaptations were not verified by this source tree. They are not claims about
the current binary.

  Repository license: GPL-2.0-or-later (per its LICENSE/readme).

That branch contains gpu/shadps4 as a vendored source tree, not as a submodule.
Its gpu/VENDOR.txt identifies shadPS4 commit
b4e7ae776071ceb1dd35004577a8719481e1d258 and lists subsequent shader-recompiler
correctness backports. The vendored license file is GPL-2.0. Its GPU CMake
target uses Vulkan and the GoW3 port's SDL/Vulkan shims; the build also requires
SDL3, FFmpeg, glslang, Zydis, Boost, fmt, VMA, and other dependencies. On
non-Windows hosts that CMake file also requires X11. This is not a drop-in
Metal implementation; Apple Silicon/Vulkan portability still needs a tested
Vulkan loader/driver path and adaptation to this project's GuestContext ABI.

Upstream revisions and licenses were inspected for integration planning only.
No upstream source was copied into this working tree during this audit.

UPDATE 2026-10-23: PINNED RECOMPILER AND FULL GPU CANDIDATE IMPORTED
-------------------------------------------------------------------
The preceding audit describes the tree before the isolated source-import
commit. The shader recompiler used by the primary diagnostic path is vendored
under gpu/shadps4-recompiler/. The complete candidate video core, Vulkan/SDL3
backend, GoW3 GPU shims, tests, and source licenses are now present under
third_party/gow3gpu/.

The authoritative provenance, dependency revisions, local macOS/ARM64 patches,
and standalone build evidence are in third_party/gow3gpu/IMPORT_MANIFEST.md.
The imported candidate is isolated: it is not linked into ps4_app and has no
live GNM import caller. The top-level gpu/gow3gpu.h and
gpu/gow3gpu_bridge.cpp remain legacy diagnostic placeholders that forward to
the native Metal renderer; their signatures are not the imported library ABI.
Use third_party/gow3gpu/gpu/gow3gpu.h as the candidate C ABI reference.

The candidate library builds for native arm64, but runtime integration remains
blocked by the incompatible guest-memory address model, unresolved
runtime_* callbacks, import-dispatch ABI, and MoltenVK's missing required
robustness2 features. No production backend switch has been made.
